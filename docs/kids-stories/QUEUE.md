# Kids' story queue

Public-domain fables and folk tales, made in order (top `todo` first). Each scheduled run
takes the first `todo`, marks it `done` with the date and YouTube video ID, and commits this
file. Retell each tale in your own words and draw your own characters: these are old public
domain stories, but specific modern film versions (e.g. a studio's character designs, songs or
names) are not, so never copy those.

Every story gets the **2026 spin** described in `.claude/skills/kids-story/SKILL.md`: the
classic plot and moral, retold in a modern world with 2–3 everyday touches (generic tech,
no brands). The "2026 spin" column is a starting idea, not a script.

Vary the settings and palettes from story to story (meadow, forest, seaside, snowy hills,
farmyard, pond, desert, night sky) so the channel never looks like one template repeated.
